# [Count Numbers with Digit 4](https://www.geeksforgeeks.org/problems/count-numbers-containing-43022/1)
## Easy
You are given a number n, Return the count of total numbers from 1 to n containing 4 as a digit.
Examples:
Input: n = 9
Output: 1
Explanation: 4 is the only number between 1 to 9 which contains 4 as a digit.
Input: n = 44
Output: 9
Explanation: 4, 14, 24, 34, 40, 41, 42, 43 &amp; 44, there are total 9 numbers containing 4 as a digit.
