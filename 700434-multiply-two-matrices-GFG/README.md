# [Multiply Two Matrices](https://www.geeksforgeeks.org/problems/multiply-matrices/1)
## Easy
Given two square matrices a[][] and b[][], each of size n * n, return the matrix obtained by multiplying a and b.
Examples:
Input: a = [[7, 8], [2, 9]], b = [[14, 5], [5, 18]]
Output: [[138, 179], [73, 172]]Explanation: Multiplying the rows of a with the columns of b gives the resulting matrix.
Input: a = [[17, 4], [17, 16]], b = [[9, 2], [7, 1]]
Output: [[181, 38], [265, 50]]Explanation: Multiplying the rows of a with the columns of b gives the resulting matrix.
