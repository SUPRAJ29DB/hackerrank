# [Diagonal Sum in Matrix](https://www.geeksforgeeks.org/problems/diagonal-sum0158/1)
## Easy
Given a square matrix of size n×n. Your task is to calculate the sum of its diagonals.
Note :&nbsp; When n is odd, there is center value which&nbsp;is counted twice in the diagonal sum.
Examples:
Input: mat[][] = [[1, 0, 1], [0, 1, 0], [1, 0, 1]]Output: 6

Input: mat[][] = [[1, 2], [3, 4]] Output: 10
Constraints:1 ≤ n ≤ 1001 ≤ mat[i][j] ≤ 10000
