# [Sum of Digits from 1 to n](https://www.geeksforgeeks.org/problems/compute-sum-of-digits-in-all-numbers-from-1-to-n2855/1?page=1&category=Dynamic%20Programming&difficulty=Basic,Easy&sortBy=submissions)
## Easy
Given an integer n, find the total sum of digits of all numbers from 1 to n.
Examples:
Input: n = 5
Output: 15
Explanation: 1 + 2 + 3 + 4 + 5 = 15
Input: n = 12
Output: 51
Explanation: 1 + 2 + 3 + 4 + 5 + 6 + 7 + 8 + 9 + (1 + 0) + (1 + 1) + (1 + 2) = 51
Constraints:1 ≤ n ≤ 6 * 107
